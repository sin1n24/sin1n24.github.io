# noindex化した記事一覧（2026-08-16）

**削除ではない**。記事ファイル・ページとも残存し、直URLでは今まで通り閲覧できる。
`noindex: true` は `src/content.config.ts` のスキーマフィールドで、`src/utils/publish.ts`
の `isIndexable()`（`isPublished` かつ `!noindex`）が効果範囲を判定する。

## 元に戻す方法

各ファイルの frontmatter から `noindex: true` の行を削除するだけでよい。
以下はその一括コマンド（PowerShellから実行、リポジトリルートで）:

```powershell
$files = @(
  "20080103-1199381670","20080206-1202312035","20080208-1202462077",
  "20081203-1228323826","20090514-1242317576","20090825-1251218628",
  "20101031-1288538626","20110607-1307462239","20111010-1318222127",
  "20111106-1320586644","20111223-1324660631","20120829-1346239955",
  "20121008-1349781489","20130419-1366378227","20130509-1368109851",
  "20130718-1374155983","20130719-1374241890","20130801-1375366356",
  "20150228-1425127977","2017-08-29-224149"
)
foreach ($f in $files) {
  $path = "src/content/blog/$f.md"
  (Get-Content $path -Encoding utf8) | Where-Object { $_ -ne "noindex: true" } | Set-Content $path -Encoding utf8
}
```

個別に戻したい場合は該当ファイルの `noindex: true` の行を1行削除するだけ。
