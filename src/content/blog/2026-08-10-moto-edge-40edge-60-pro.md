普段メインで使っているスマートフォンを新調したので、そのご報告と簡単なレビューをしたいと思います。

これまで愛用していた「motorola edge 40」(画像下側)から、最新モデルの「motorola edge 60 pro」(画像上側)に乗り換えました！

![画像](https://sin1.studio/img/blog/2026-08-10-moto-edge-40edge-60-pro-1786364098081-2.jpg)

# 1. 乗換えた背景

edge40も薄くて軽くてお気に入りだったのですが、長く使い込んでいくうちに少し使うだけでバッテリーが1日持たず不便になってきました。edge40固有の機能や使用感は気に入ってた所、同じメーカーedge60 proが安くなっていたので、思い切って乗り換えることにしました！

# 2. 性能比較（スペックの違い）

edge40からedge60 proで、実際にどれくらい進化したのか、主なスペックを比較してみました。

| 項目 | moto edge 40 (旧) | motorola edge 60 pro (新) |
| :--- | :--- | :--- |
| **SoC (CPU)** | MediaTek Dimensity 8020 | MediaTek Dimensity 8350 Extreme |
| **メモリ/容量** | 8GB / 256GB | 12GB / 256GB |
| **ディスプレイ** | 6.55インチ pOLED (144Hz) | 6.7インチ pOLED (120Hz) クワッドカーブ |
| **バッテリー** | 4,400mAh (68W急速充電) | 5,000mAh (125W急速充電) |
| **アウトカメラ** | 5000万(メイン) + 1300万(超広角/マクロ) | 5000万(メイン) + 5000万(超広角) + 1000万(光学3倍望遠) |
| **重量** | 約171g | 約184g |

**処理能力の向上**：SoCが8350 Extremeに、メモリも12GBに増強され、重い処理やマルチタスクも余裕に

**カメラが3眼に**：Edge 40は2眼でしたが、60 proは「光学3倍望遠」と「5000万画素の超広角」が追加

**バッテリーと充電速度**：バッテリー容量が5,000mAhに増え、充電速度も脅威の「125W」に進化

# 3. 実際の使用感・レビュー
## デザインと持ちやすさ

画面サイズが6.7インチに大きくなり、重量も十数グラム増えましたが、今の所気になっては無いです。クワットカーブがどうこうありますが、以前も丸みあったので、そんな変わりはないです。

## サクサク感・動作について

メモリが増えたのと新しいSoCのおかげで、アプリの切り替えや調べ物をしながらの作業も非常にスムーズです。具体的にはedge40では以前は出来たのに、最近はゲーム（FGO)を起動後にブラウザで調べて戻るとアプリが落ちてしまうようになって不便でしたが、edge60proは全然問題ありません。

## カメラの使い勝手

望遠レンズが搭載されたのが個人的にはすごくありがたいです！マクロ撮影と合わせて、色々な構図で綺麗に撮れるようになりました。moto aiによる補正も（今の所）自然で良い感じです。

## バッテリー＆爆速充電

125Wの充電スピードは本当に凄いです！出発前の15分充電器に繋ぐだけで50%からほぼ100%に回復するので、出発前のもうちょっと充電してから～のストレスがなくなりました。（以前も良かったけどさらに早くなった）

# 4. まとめ

Edge 40の「軽さ・薄さ」も魅力的でしたが、Edge 60 proの「カメラ性能」「バッテリー＆爆速充電」、そして「サクサクな動作」は、乗り換えて正解でした！

しばらくはこのスマホを新しい相棒にして、また色々な活動記録や製作の様子を残していきたいと思います。
